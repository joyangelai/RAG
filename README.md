# RAG (Retrieval-Augmented Generational) Pipeline

This is a localized RAG Document Q&A Pipeline.
It is built to extract text from multi-page PDFs and generate accurate, non-hallucinatory answers using local execution streams.
The core architecture eliminates expensive cloud API costs and data privacy leaks by hosting open-source embedding indexes and foundational Large Language Models (LLMs) completely on edge runtime hardware.


1. Document Ingestion & Chunking
2. Local Vectorization and Storage
3. Contextual Retrieval
4. Offline Inference Generation
